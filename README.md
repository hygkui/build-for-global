出海黄金组合 

本项目的目的是生成技术栈组合，并且能够配置好直接生成模板文件。

形式是： 
1. 提供web界面，创建项目，勾选技术栈，并且内置ai，随时咨询问问题。
2. 保存不同的模板，可以分享和导入
3. 支持cli，方便的管理自己的模板
4. 完善的文档说明
5. skills支持导入
6. 可以是npm包
